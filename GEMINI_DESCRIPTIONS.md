# Описания каталога через Gemini

## Рабочая генерация

Модель по умолчанию `gemini-3.1-flash-lite`. Рабочая цепочка: Serper → проверка страниц → Gemini → MongoDB. Google Search Grounding и OpenAI не используются. Serper получает только название; Gemini получает название, описание поставщика и структурированные результаты проверки источников. Цена, остатки, размеры и данные покупателей не отправляются. Генерируется украинский текст без заявлений об оригинальности и неподтверждённых технологиях. Программные проверки ограничивают риск выдуманных утверждений, но не доказывают фактическую точность каждого предложения.

Исходный текст сохраняется в `supplierDescription`, опубликованный — в `description`, метаданные — в `aiDescription`. Готовые результаты и ошибки хранятся в MongoDB `catalog_description_jobs`, блокировка, счётчик запросов и паузы — в `catalog_description_control`.

Поиск кэшируется в `catalog_model_research` по нормализованному полному названию (бренд, модель, поколение, модификация и цвет). Готовые совпадения используются повторно; отрицательный результат повторно проверяется не раньше чем через 7 дней. При сбое Gemini повторного платного поиска нет. Ключ кэша описания включает нормализованные название, исходное описание и версию инструкции. Размеры, цены и остатки не вызывают повторную генерацию. Цвет и модификация остаются частью названия: объединять их без подтверждения одинаковых характеристик нельзя. Описания с отличающимися исходными характеристиками не объединяются. Изменение исходных данных создаёт новое задание; старый результат никогда не используется как источник для следующей генерации.

## Настройки

- `SERPERAPI` (или `SERPER_API_KEY`) — серверный ключ Serper, необходимый для рабочей очереди.
- `SERPER_DAILY_LIMIT=1000` — максимум попыток поиска за сутки UTC; один стандартный запрос на новое имя, без автопокупок кредитов.
- `GEMINIDESCRIPTIONAPI` (или `GEMINI_API_KEY`) — серверный ключ Google.
- `GEMINI_DESCRIPTION_MODEL` — необязательное имя модели.
- `GEMINI_DESCRIPTIONS_ENABLED=false` — отключает автоматический обработчик веб-сервера.
- `GEMINI_DESCRIPTION_DAILY_LIMIT=2000` — максимум попыток API за сутки UTC, включая неудачные. Это предел запросов, не гарантия бесплатности тарифа Google.
- `GEMINI_DESCRIPTION_INTERVAL_MS=10000` — минимальная пауза между последовательными заданиями.
- `MONGODB_URL` и ключи Algolia/Typesense — существующие серверные настройки для записи и репликации.

`GEMINIPRNAME` не выбирает проект API: проект определяется ключом. Никогда не переносите ключи во frontend, Git или `NEXT_PUBLIC_*`.

После запуска новой версии сервера (`npm start`) обработчик включается автоматически при наличии Gemini-ключа и Serper-ключа. Он обнаруживает товары, созданные любым способом, включая XML, примерно в течение минуты, если нет очереди или паузы API. Импорт XML атомарно сохраняет AI-описание той же модели, даже если генерация завершилась после чтения каталога импортёром. Данные XML записываются отдельно в supplierDescription. При изменении исходных характеристик старый текст остаётся до успешного обновления; при смене названия используется текст нового товара. На хостинге нужно развернуть эту версию и добавить Gemini-ключ и Serper-ключ в окружение сервера: локальный `.env` туда не переносится автоматически.

## Команды

```sh
# Только статистика, без Gemini и без записи
npm run generate:descriptions

# Один товар, реальная генерация и публикация
npm run generate:descriptions -- --apply --product 6ad1bae3f0cbfd50fd7dd709 --limit 1

# Пакетная обработка с остановкой при ошибке/паузе/исчерпании очереди
npm run generate:descriptions -- --apply --limit 2000

# Продолжать ожидание новых товаров и повторов; остановка после 2000 записей или SIGTERM/SIGINT
npm run generate:descriptions -- --apply --watch --limit 2000
```

MongoDB-блокировка сериализует CLI и экземпляры веб-сервера, истекает через 10 минут после аварийного завершения. Готовый результат сохраняется до публикации. Запись сравнивает исходные поля, чтобы не затереть параллельный импорт или ручное изменение. Репликация в поисковые индексы повторяется отдельно и не запускает новую платную генерацию.

При 429, 400, 401, 403 и 404 очередь делает общую паузу 6 часов. При 5xx — 5 минут. Временные ошибки 5xx повторяются без окончательного отказа (в пределах дневного лимита). Ошибки генерации/валидации повторяются до трёх попыток, затем задание получает статус `failed` для ручного разбора. Исходное описание остаётся доступным. Пустые исходники пропускаются. Произвольные модели не перебираются, тарифы не изменяются.

## Предварительный просмотр и историческое исследование

`scripts/testGeminiDescription.js` остаётся отдельной диагностической командой. Для черновика без записи и без поиска обязательно укажите `--supplier-only`:

```sh
npm run test:gemini-description -- --product 6ad1bae3f0cbfd50fd7dd709 --supplier-only
```

Без этого флага старый диагностический сценарий пробует Google Search Grounding, который для текущего проекта возвращал 429. Он не вызывается рабочей очередью. Отчёты в `sync-reports/` игнорируются Git. Ни тестовый просмотр, ни чтение статистики не публикуют описания.


## Проверка результатов Serper

Поиск `/search`, максимум 10 результатов. Приоритет официальных доменов производителей среди найденных совпадений. До трёх страниц читаются с ограничениями времени, размера ответа и разрешённых доменов. Ключ Serper никогда не отправляется на сайты магазинов. Неизвестные домены и перенаправления на них не открываются. Список разрешённых доменов находится в `serperResearch.js`.

Проверка полного имени выполняется и по поисковому заголовку, и по заголовку самой страницы. Различия поколения, модификации и цвета не игнорируются. Gore-Tex/GTX и Gray/Grey нормализуются. Артикул не обязателен. Отсутствие совпадения не доказывает отсутствие модели.

Поисковые сниппеты не считаются подтверждением факта. Сохраняются ссылки, тип источника, время проверки, хеш прочитанного текста и небольшой фрагмент о материалах. В Gemini передаются только базовые материалы (кожа, текстиль, замша), одновременно указанные поставщиком и на прочитанной странице совпавшей модели. Искусственная кожа не превращается в натуральную. Даже такое совпадение не является независимой экспертизой товара. Технологии оригиналов, водозащита и обещания эксплуатационных свойств не переносятся. Новые характеристики, которых нет у поставщика, требуют отдельного подтверждения и автоматически не публикуются.

Если точных доступных страниц нет, результат сохраняется как `unconfirmed`, а описание ограничивается исходными данными поставщика. Это явно записывается в исследование, а не выдаётся за найденные характеристики. Если сам Serper отвечает ошибкой, генерация не начинается: очередь сохраняет ошибку с префиксом `SERPER_` и делает паузу. Квота Gemini резервируется только после успешного этапа поиска/кэша.

## Расширенные описания v3

Версия `uk-serper-expanded-v3`: 3–4 абзаца, ориентир 140–220 слов, короче при недостатке подтверждённых фактов. Смена версии обновляет все описания, сохраняя кэш поиска Serper. Оригинальность и технологии оригинала не заявляются. Исходный текст хранится отдельно и не заменяется AI-текстом.

Защита импорта действует после публикации изменений в репозитории, из которого GitHub Actions запускает ежедневный импорт. Для автоматической генерации на хостинге нужны новая версия сервера и оба API-ключа; локальная служба обрабатывает также новые товары, пока компьютер включён.
