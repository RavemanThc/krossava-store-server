# Пробные описания товаров через Gemini

Команда читает один товар из MongoDB, отправляет Google только название и очищенное описание поставщика, сохраняет JSON-черновик в игнорируемый каталог `sync-reports/`. Цены, остатки, данные покупателей, ключи других сервисов и Telegram-сессия в запрос не включаются. База данных, поисковые индексы и сайт не изменяются.

## Конфигурация сервера

- `GEMINIDESCRIPTIONAPI` — существующее имя API-ключа в локальном `.env`. Также поддерживается стандартное `GEMINI_API_KEY`.
- `GEMINI_DESCRIPTION_MODEL` — необязательное имя модели (по умолчанию `gemini-3.1-flash-lite`); параметр `--model` имеет приоритет.
- `GEMINIPRNAME` — название проекта, не имя модели и не credential. Для Gemini Developer API аутентификация выполняется ключом, поэтому имя проекта не отправляется.
- `MONGODB_URL` — существующее подключение к каталогу.

Не переносите ключ в frontend или переменные `NEXT_PUBLIC_*`. `.env` и отчёты не должны попадать в Git.

## Пробный запуск

```sh
npm run test:gemini-description -- --product 6ad1bae3f0cbfd50fd7dd709 --model gemini-3.1-flash-lite
```

Один запуск — один запрос генерации. Автоматических повторов, массовой генерации и записи описаний в товары нет. Запрос может расходовать квоту/оплачиваться по тарифу проекта Google.

Отчёт содержит исходные факты, хеш исходника, модель, время, расход токенов, описание, список характеристик и недостающих фактов. Флаги `requiresReview: true` и `applied: false` означают, что текст ещё не опубликован.

Промпт требует украинский язык и запрещает выдумывать характеристики, оригинальность, сертификацию, гарантии, цены, доставку и медицинские свойства. Проверка ответа отклоняет HTML, некорректный JSON, пустые поля и незавершённую генерацию. Это не заменяет проверку фактической точности человеком: перед публикацией сравните каждое утверждение с источником.

При ошибках выводятся только безопасные статусы. HTTP 404 может означать недоступность конкретной модели для ключа, 403 — ограничения доступа, 429 — квоту. Успешное получение списка моделей само по себе не подтверждает возможность генерации.

## Результат первого подключения

23 ноября 2026 года: список моделей получен успешно. Gemini 2.5 Flash вернула HTTP 404; Gemini 3.5 Flash не завершила запрос за 45 секунд. Gemini 3.1 Flash Lite успешно создала черновик для ASICS GEL-Kayano 20 GTX: 277 входных, 161 выходной, всего 438 токенов. Каталог не изменён. В ответе цвет ошибочно перечислен среди недостающих фактов, несмотря на цвет в названии: это пример необходимости редакторской проверки.
